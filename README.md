# Parcial 2 – Informática II (UdeA, 2026-2)

Sistema de monitoreo de personas con esquizofrenia bajo estímulos sensoriales (EEG / ERP).

- `clases.py`: funciones de validación y clases `ArchivoCSV`, `ArchivoMAT` y `Sistema`.
- `main.py`: menú principal (ejecutar este archivo).
- Imágenes `.png`: gráficas generadas en las pruebas.

Ejecutar: `python main.py`
Librerías: numpy, pandas, scipy, matplotlib.
